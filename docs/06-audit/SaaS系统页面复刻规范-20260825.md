# SaaS 线上系统页面字段级复刻规范

> **目标**：把 SaaS 线上系统（saas-tenant.ryrkxn.cn，hhh 项目）对应模块的功能按页面字段级 1:1 复刻到 SaaS-Class 原型，再在此基础上修改并标记（红色字体标记新增/修改点）
> **登录**：13300000000 / 验证码 1502 → 选互联网 → hhh 项目
> **工具**：agent-browser（open/snapshot -i/screenshot）

## 复刻原则

1. **1:1 复刻原系统页面**：字段名、字段顺序、按钮、筛选区、表格列、状态枚举、操作按钮完全对齐
2. **红色标记修改点**：原系统没有的（新增功能/新增字段/新增按钮）全部用 `<span style="color:red">` 标记，并在行尾加 `【新增·课程业务】` 注释
3. **保留原系统字段**：原系统的字段即使课程业务用不到也保留（如商户号/商户key 等财务字段）
4. **技术栈**：Vue3 + ElementPlus + Pinia（对齐 SaaS-Class 现有技术栈，不是 SaaS 线上的 React）
5. **页面放 `projects/SAAS/src/pages/saas-replica/`**：按域分目录，如 `organization/` `order/` `aftersale/` `finance/` `marketing/` `store/` `course/`

## 6 项决策的修改标记规范

| 4 退款进售后域 | 售后类型新增"课程退款" | 红色 `课程退款` + 【新增·课程业务】 |

## 已抓取的 SaaS 线上系统页面字段（团队参考）

### 1. 组织管理（已抓取）
- 左侧组织架构树：组织名称/组织身份/业务类型/合作类型/操作(新建/编辑/代理/删除)
- 树根=总部，下级=招募代理/招募渠道
- 右侧成员列表：成员名称/成员电话/资质状态/主体类型/主体名称/社会信用代码/注册地址/上级人员/下级成员数/账户数
- 添加成员弹窗：基本信息(成员名称*、成员电话*、内部/外部单选、是否提交资质*) + 业务信息(终端销售等单选)
- **修改点**：角色枚举新增"讲师/助教"（红色标记）

### 2. 账户管理（已抓取）
- 筛选：创建时间/用户编号/账户类型(全部下拉)
- 表格列：序号/用户编号/用户名称/联系电话/主体类型/账户类型/钱包ID/钱包个人名称/商户号/商户key/商户秘钥/状态/操作
- **修改点**：账户类型枚举新增"讲师/助教"（红色标记）

### 3. 订单管理（已抓取）
- 筛选区：商品名称/售后信息/订单类型/订单状态/搜索时间(下单时间)
- 订单状态枚举：全部/待发货/已发货/售后中/设置售后
- 订单类型枚举：快递发货（等）
- 表格列：商品信息(订单号+商品+规格+数量+单价) / 售后信息 / 实收金额 / 买家收货人 / 下单时间 / 订单状态 / 订单类型 / 买家备注 / 操作(详情/备注/查看)
- 操作按钮：展开/搜索/重置/批量全选/批量退款
- **修改点**：订单类型新增"课程订单/训练营订单"（红色标记）

### 4. 售后管理（已抓取，菜单存在，页面未深入）
- 位置：交易菜单下，与订单管理并列
- **修改点**：售后类型新增"课程退款"（红色标记）

### 5. 分佣管理（已抓取）
- 4 子菜单：创建政策/政策列表/分佣账户/佣金明细
- **修改点**：创建政策的政策类型新增"课程分成"（红色标记）

### 6. 课堂（已抓取）

- 课程库列表：课程编号/课程名称/所属分类/课程视频内容/课程相关题库/创建时间/状态/操作(查看视频/查看题库/编辑/禁用)
- 课程库新增表单：课程名称 + 所属分类（仅 2 字段）
- **修改点**：整个课堂域扩展到 19 个功能（全部红色标记新增页面）

### 7. 营销域（未抓取，需团队抓取）

## 团队任务分配

每个 team member 负责 1 个域：
1. 用 agent-browser 登录 SaaS 线上系统，进入自己的域
2. 逐页面 snapshot -i 抓取字段（列表/表单/筛选/操作）
3. 在 `projects/SAAS/src/pages/saas-replica/{域}/` 下 1:1 复刻页面（Vue3+ElementPlus）
4. 按决策标记修改点（红色字体 + 【新增·课程业务】）
5. read_lints 验证 0 错误
6. 报告：复刻了哪些页面，标记了哪些修改点
