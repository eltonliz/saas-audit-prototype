## 一、会议概要

1. 课程/训练营以**虚拟商品**形态接入现有 SaaS 电商交易链路（一套订单、不复用维护两套）。
2. 讲师定位为**主播式独立角色**（平台指定、可动态调配），APP 端不再提供讲师/助教角色切换。
3. 本期范围大幅裁剪：答疑/合同/证书/分成/提现/测验均不做，核心聚焦「课时 + 评价 + 购买学习 + 数据看板」。
4. 报名交互从简：报名即购买、0 元购产生虚拟订单，审核开关默认关闭。
5. 排期：08/30-08/31 二次技术预审 → 09/01 开发启动 → 约 09/15 交付。

## 五、新增需求明细（M0828-09 ~ M0828-13）

### M0828-09 报名=购买从简（🟢）

- C 端按钮统一显示"**购买**"（不做"报名/购买"两套按钮与组件判断）；免费课程/训练营 = **0 元购**，产生 0 元虚拟订单。
- 列表/营期卡片加"**正在报名中**"标签。
- 报名审核开关（`require_review`）保留，**默认关闭**；开启时走报名→审核→通过→支付链路（少量场景，后续按客户反馈调整文案）。
- 会议裁决："先从简实现，文字表述后续再改，客户反馈后再调"。
- 变更：BR-ENROLL-005 补充按钮与 0 元购口径；§13.2 报名交互对齐。

### M0828-10 课程展示开关 + C 端课程列表独立结构（🟢）

- 创建课程/训练营时可选"**是否展示**"（C 端愿展示则展示，不愿则收起）；后台可设专区选择课程放出。
- C 端列表用**课程列表结构**，**不套商品列表结构**（数据结构不同）。
- 变更：§12 Course/Camp 实体补展示字段；§13.2 首页/专区需求。

### M0828-11 APP 布局调整（🟢）

- **不加底部"课堂" tab**（底部 5 个 tab 已满）。
- 课程入口改为四处：① 首页金刚区；② **内容推荐栏**（课程与直播融合展示——"即将开课"内容也在推荐流中，体现课程↔直播无缝切换）；③ "我的"页入口；④ 直播"更多"页增加"课程"分类。
- 变更：§13.2 首页需求重写；`KnowledgeHomePage.vue`/`HomePage.vue` 对齐。

### M0828-12 课程详情页独立结构（🟢）

- 课程详情页**独立设计**，不套商品商详页（规格参数/物流不适配）；结构"范围贴合"现有商详框架。
- 支持试看（仅前几章/节），购买后解锁全部。
- 评价仅显示**条数 + 星级**，不显示评价内容；商家回复 C 端可见。
- 变更：§13.2 课程详情需求；`CourseDetailPage.vue` 调整。

### M0828-13 营期直播带货（🟢）

- 营期可穿插**直播带货**：营期直播可挂直播商品车（普通商品/课程/训练营）。
- 与直播域 D09 联动；录播/直播走现有 SaaS 通道。
- 变更：§13 营期功能补直播带货需求；§22 标注直播域接口依赖。

## 十一、V2 更新：0828 晚间一揽子决策（会后补充）

> 来源：用户会后明确指示。**两条决策优先级高于本表 §三~§六 全部交易相关结论。**
> 核查方式：研读 SaaS 系统 PRD 总索引/系统整合版/APP域/直播域 + 登录真实后台（saas-tenant.ryrkxn.cn，hhh 项目）逐菜单核查。

### D2-1 本期不做交易相关

- **决策**：所有课程、训练营均由后台直接发布，APP 侧直接观看（免费），**不产生订单/支付/退款/分成/提现，SaaS 系统订单域、交易域完全不受影响**。
- **影响范围**：推翻 M0828-01（虚拟商品落商品域）、M0828-02（虚拟商品类型）、M0828-05（订单详情两套）、M0828-09（报名=购买/0元购）、M0828-14（积分赠送）；PRD v1.4.3 的 `BR-ORDER-C01~C03`、`D-v14-3`（课程/训练营订单类型）全部**下期再议**。
- **对 SaaS 系统的价值**：商品域/订单域/交易域/售后域/财务域 **零改动**，课程域变成纯内容域（对标录播域 D10 的内容属性），改造范围从"7 域 + 1 新域 200+ 功能点"骤减。
- **技术承接**：真实后台核查确认「直播 → 直播录播 → 新增录播 → 展示风格 = 直播间/课程」能力已存在（录播列表含"录播课程"数据、课程风格展示、修改可见范围、观看统计）。**课程 C 端展示与观看链路可直接复用录播域能力**，课程域仅做内容管理 + 学习进度。

### D2-2 去掉讲师、助教角色

- **决策**：系统**不引入讲师/助教角色**（比 M0828-03 更彻底：连"组织结构新增讲师/助教角色"也不再提），课程与讲师的关联弱化为内容属性，PC 后台沿用现有店长/店员体系，APP 只有学员视角（+切换身份到店长/店员看管理入口）。
- **对 SaaS 系统的价值**：门店域/分销域/组织管理**零改动**（真实后台已核实：组织管理为总部→代理→终端三层，成员字段无讲师/助教）。
- **原 v1.4.3 的"讲师/助教资质审核暂缓（建档即生效）"** → 升级为"讲师/助教实体与角色整体不建"。

### V2 决策下的本期形态（一句话）

> **本期 = 纯内容课堂**：后台建课程/课时/视频/音频 + 建营期/排课 + C 端（复用录播课程风格链路）直接看 + 学习进度/评价/看板；直播带货走直播域既有能力。**不碰商品/订单/交易/售后/财务五域。**
