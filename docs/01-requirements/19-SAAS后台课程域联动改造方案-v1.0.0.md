## §2 背景与目标

### 2.1 背景

SaaS-Class 课程与营期域已完成以下改动（基于会议纪要 2026-08-20）：
- 课程库加"授课方式"（录播/直播）+ "是否公开" + "是否属于营期"
- 课程即课时，删除课时管理
- 营期排课去日历改列表，审核通过后锁定
- 营期最大 90 天，开营后不能退款，开营后分账
- 删除自建直播场次/中控，复用 SAAS 平台直播模块
- 录播脚本挂商品在 SAAS 平台做

这些改动需要 SAAS 线上后台 7 大模块联动改造，才能实现课程→直播→录播→商品→分账的完整闭环。

### 2.2 目标

- 课程域改动不影响 SAAS 后台现有功能
- 课程/营期与直播/商品/分佣等模块数据联动
- 录播脚本挂商品复用现有商品体系
- 开营后退款/分账约束落地到 SAAS 后台

```

触发点：
  - 终端：createRefundRequest 时校验
  - PC 端：approveRefund/handleRefund 时校验
异常：营期已开营，不支持退款
```

## §14 数据联动关系图

```
课程库（授课方式=录播/直播）
  ├── 录播课程 ──→ 素材中心（录播视频分类）引用视频
  │     └── 审核通过 ──→ 直播录播（自动创建录播数据）
  │           └── 录播控制 ──→ 商品脚本（时间触发挂商品）
  │                 └── 商品来源 ──→ 商品管理（平台商品）/ 门店商品（门店商品）
  │
  ├── 直播课程 ──→ 直播模块
  │     └── 审核通过 ──→ 计划管理（自动创建计划，类型=课程直播）
  │           └── 主播 = 课程主讲讲师
  │           └── 计划 ──→ 场次管理（自动生成场次）
  │                 └── 场次 ──→ 直播间
  │
  └── 营期（授课方式=录播/直播）
        ├── 录播营期 ──→ 排课（选录播课）──→ 课时自动生成
        ├── 直播营期 ──→ 排课（审核通过锁定）
        │     └── 审核通过 ──→ 计划管理（自动创建计划，类型=营期直播）
        │           └── 主播 = 营期主讲讲师
        │
        ├── 报名 ──→ 订单管理（订单类型=营期订单）
        │     └── 支付成功 ──→ 合同
        │
        ├── 售后 ──→ 售后管理
        │     └── 开营拦截（in_progress/ended 时不能退款）
        │
        └── 分佣 ──→ 分佣管理
              └── 开营后结算（in_progress 时触发佣金结算）
              └── 营期分成政策（讲师/助教/平台三方比例）
```

## §15 风险与约束

### 15.1 风险

| 风险 | 等级 | 缓解措施 |
|---|---|---|
| 直播模块联动改动量大，可能影响现有直播功能 | 高 | 分阶段上线，先加类型再自动创建 |
| 开营拦截守卫可能影响在途退款 | 中 | 上线前排查在途营期订单 |
| 分佣政策扩展可能影响现有分佣计算 | 中 | 新政策类型独立，不修改现有政策 |
| 订单类型扩展可能影响现有订单查询 | 低 | 新增类型不影响现有类型 |

### 15.2 约束

- SAAS 后台改动不影响现有非课程域功能
- 课程/营期与直播/分佣的联动需保证数据一致性
- 开营后退款/分账约束必须终端+PC端双守卫
- 录播脚本挂商品复用现有商品体系，不单独建设
