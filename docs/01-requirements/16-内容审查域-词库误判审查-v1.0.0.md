## 1. 结论摘要

原始词表直接可用会大量误封日常对话。三档处理后：

| 处理 | 词数 | 说明 |
| --- | --- | --- |
| ✂️ 直接删除 | 262 | 占位符（永不命中）、单字/双字母子串灾难、日常高频词、合法类目与新闻用语 |
| ⬇️ 下沉 L3 疑似词 | 263 | 依赖上下文才能判定，命中仅「记录」转人工，不触发封禁/断流 |
| ✅ 保留 L1/L2 | 1339 | 特异性强，日常语境基本不会出现 |

## 2. 审查口径

- **删除**：单字与双字母（裸子串必误伤）、日常高频多义词、正常商业/医疗/新闻用语、含 `XX/某某` 的占位符。
- **下沉 L3**：强多义词（日常义常见、违规义需上下文），或属合法类目但灰产常滥用。对应 `custom` 类别（L3，仅记录）。
- **保留**：特异性违规词；同义词变体/拼音变体保留（对抗绕过）。
- **去重**：跨表重复（母狗、蒙汗药、听话水等）保留单一来源。

## 5. 配套机制建议（写入 PRD 修订待办）

1. **匹配策略**：≤2 字的词仅做「全词/分词边界匹配」，禁止裸子串（含 `includes`）；拼音与变体词仅精确匹配。
2. **豁免白名单**：命中后先查白名单短语（如「唐氏筛查」「老年痴呆」「波霸奶茶」「穷鬼套餐」「上门取件」），命中白名单直接放行。
3. **分级联动**：L3 词库命中仅记录转人工，L2 警告，L1 才断流——与 `audit-level-config.ts` 类别定档一致；本次 263 个下沉词全部进 L3。
4. **腾讯云兜底**：本词库是平台侧「类别定档」辅助，主审核仍以腾讯云 Label/score 为准，误杀由 Score<50 降档与人工复核兜底（BR-AUDIT-009）。
5. **回归机制**：L3 词库每月用真实样本回归一次，确认无误杀的可升回 L1。
