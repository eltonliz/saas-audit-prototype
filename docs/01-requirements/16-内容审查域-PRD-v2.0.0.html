§ 03

背景与问题陈述

内容审查域是 SAAS 平台的平台级运营管控能力，针对主播直播内容（音频/视频推流）进行实时审查和擦音处理，并对回放文件执行违规处理与人工发布管控，确保直播与回放内容符合法律法规要求。

核心问题

编号问题严重程度
AUDIT-ISSUE-001直播中主播出现违规内容无实时擦音能力🔴 高
AUDIT-ISSUE-002直播回放文件未经擦音处理即开放观看🔴 高
AUDIT-ISSUE-003回放断流产生多片段时无法可靠拼接为完整文件🔴 高
AUDIT-ISSUE-004平台对违规内容缺乏分级管控与人工处置闭环🟡 中

需求边界

管控对象审查内容技术方案V2
主播直播内容音频/视频流（画面 + ASR 文本）腾讯云直播审核 + 擦音（真实对接）✅
回放文件音频擦音 + 片段拼接 + 人工发布腾讯云 AMS + FFmpeg concat✅
观众文本消息弹幕/聊天腾讯云 IM 云端审核（独立体系，不在本域）❌

级别体系（平台自定义三级）

腾讯云仅返回 Label / subLabel / score / suggestion，不提供级别划分。级别为平台业务层自定义（详见子文档《级别判定规则》）：

级别名称告警色处置方式可否降级
L1高危红审核引擎直接断流 + 封禁❌ 不可降级
L2中危黄运营可记录 / 断流❌ 不可降级
L3低危蓝运营可记录 / 忽略✅ 部分可降级（score<50 降一档转人工）
L1 不可降级七类 · 涉黄 / 涉政 / 涉暴 / 公共安全 / 社会安全 / 违法乱纪 / 广告法 —— 无论置信度高低一律维持 L1，租户不可关闭、不可降级，由腾讯云配置层强制执行。

L4 作为兜底级（未命中或边缘内容，仅记录备查）保留定义，页面仅展示 L1/L3 三档统计。级别判定采用三层结构：标签归类 → 类别定档 → score 校准（<50 且可降级才降一档并转人工复核）。

§ 05

范围

In-Scope（V2）

运营后台（PC）

  • 租户管理列表新增「内容审查」开关列（开启直接生效；关闭弹二次确认弹窗，含七类不可降级底线提示与在播场次警告）

租户后台（PC）—— 直播中控

  • 直播列表入口复用（直播中控台 / 更多→历史违规列表 / 更多→查看回放 / 回放管理 Tab）
  • 内容审查页签：实时违规告警（红/黄/蓝三档统计 + 待处理角标 + 实时列表）
  • 违规详情抽屉（证据录音试听 + 处置按钮按级别收敛）
  • 违规处置（记录 / 断流 / 忽略；处置说明≥10 字；30 秒超时自动记录）
  • 处理方式切换（静音 / 提示音覆盖，实时同步观众端）
  • 主播侧警示条（记录=橙色 8 秒；断流=红色常驻；观众无感知）
  • 历史违规列表（已结束场次只读档案）

租户后台（PC）—— 回放管理

  • 回放管理列表（待核对 / 已发布 / 已驳回三态 + 待核对徽标 + 删除）
  • 回放页：片段/文件逐个审核 → 勾选一一对应 → 手动拼接 → 人工发布（v2.0.0）
  • 无违规场次免擦音（源码即对外发布版）
  • 已发布查看模式（仅展示完整文件，隐藏操作区）
  • 擦音前后对比 / 播放器时间轴违规标记复审

观众端（H5 375px）

  • 静音处理效果（🔇 + 画面变暗 + 进度条，2-5 秒）
  • 提示音覆盖效果（🎧 + 声波动画，2-5 秒）
  • 判定未送达提示（与处理效果互斥）
  • 断流结束页（「直播已结束，该直播因内容违规已被终止」）

平台侧基础设施

  • 审核回调接入服务（网关验签 + 幂等去重 + 级别判定 + MQ 分发）
  • WebSocket 实时推送（中控告警 / 观众端擦音指令）
  • 断流指令通道（审查服务 → 腾讯云 DropLiveStream）
  • 回放擦音任务（AMS）与拼接任务（FFmpeg concat）调度

Non-Goals

  • 观众弹幕/评论审查（腾讯云 IM 独立处理）
  • 自研推流端审查能力（依赖腾讯云）
  • 违规统计看板（V3）
  • 平台管控策略下发（V3）
  • 租户个性化规则扩展（V3）
  • 腾讯云审核模板/擦音任务的配置管理界面（由平台运维在腾讯云控制台人工配置，系统仅消费回调与任务结果）

§ 10

功能需求列表与用例（FN / UC）

共 8 个功能需求（FN）映射 12 个用例（UC，含弹窗卡与入口卡）。每个 FN 卡片含属性、基本流程、备选流程与数据范围。

FN-AUDIT-INFRA-001审核回调接入服务（基础设施）[系统自动] 事件驱动
前置条件
  1. 腾讯云直播审核已开启并配置回调地址（回调模板由平台运维在腾讯云控制台人工配置）
  2. 审查服务与 MQ 已就绪
基本流程
  1. [系统自动] 腾讯云审核引擎对推流执行实时审核（音视频画面 + ASR 音频文本），命中违规即回调 POST /audit/callback（携带签名与 Label/subLabel/score/suggestion/asr_text/duration/seq/stream_id 等字段）
  2. [系统自动] 回调网关验签（签名不合法直接拒绝，返回 401，不进入业务）
  3. [系统自动] 幂等去重（按回调唯一键去重，重复事件返回 200 但不重复入库）
  4. [系统自动] 验签去重通过后立即返回 200 ACK
  5. [系统自动] 事件写入 MQ，异步分发至审查服务
  6. [系统自动] 审查服务执行级别判定（三层：标签归类 → 类别定档 → score 校准，输出 L1/L2/L3）
  7. [系统自动] 违规记录入库（含原始回调 JSON 留档，BR-AUDIT-010）
  8. [系统自动] 多路分发：直播中控（WebSocket 实时推送告警，待处理角标 +1）；观众端（下发擦音指令，按租户处理方式：静音/提示音覆盖）；L1 事件（腾讯云配置层已自动断流，回调携带断流结果，中控直接展示已断流状态）
  9. [系统自动] 若租户审查开关已关闭：L2/L3 事件不再产生与分发；L1 事件（七类不可降级）仍强制执行并展示
备选流程
  • 6a. 回调投递失败（网络异常）→ 腾讯云按其重试策略重投；网关侧幂等去重保证不重复入库
  • 8a. WebSocket 推送失败 → 观众端展示「直播中控尚未收到此违规的判定结果」提示（与处理效果互斥）；恢复后自动续接
  • 9a. 开关中途关闭 → 按规则 BR-AUDIT-020 处理（违规列表只读 + 待处理自动归档，L1 除外）
数据范围与后置条件
R / W
R: 回调报文 · W: 违规记录、分发日志
后置条件
验签通过的回调 100% 入库（BR-AUDIT-005）；三端按规则收到分发
关联 UC
UC-AUDIT-002 / UC-AUDIT-004
FN-AUDIT-PC-001租户内容审查开关管理[手动] + [系统自动] · 运营后台 PC
前置条件

平台运营已登录运营后台，进入「租户管理」列表页

基本流程
  1. [手动] 平台运营在租户管理列表定位目标租户（支持关键词 + 启用状态筛选）
  2. [手动] 点击该租户行「内容审查」列的开关
  3. [系统自动] 开启：直接生效，toast 提示「已开启内容审查」，开关变绿（无确认弹窗）
  4. [系统自动] 关闭：弹出「确认关闭内容审查」二次确认弹窗：租户摘要区（租户名称脱敏、直播推流地址、今日违规数）；影响说明（中控台不再显示 L2 和 L3 级别的审查记录、观众端不再做擦音处理、回放文件不再处理违规内容）；不可降级底线提示（涉黄/涉政/涉暴等七类不可降级内容仍由平台强制执行审查）；在播场次警告（红字提醒当前在播场数及关闭后的即时影响）

BR-AUDIT-017场次结束归档规则：场次转「已结束」→ 违规列表只读、处置按钮隐藏、不再接收新违规，记录保留可查
BR-AUDIT-018审查关闭清理规则：关闭后 L2/L3 事件不再产生与展示；已产生违规记录保留可查，不再追加 L2/L3 新记录
BR-AUDIT-019回放擦音异常降级规则：擦音超时→播放器锁定+可重试；擦音失败→展示原片+「尚未完成擦音处理」警告标注+可重试
BR-AUDIT-020开关运行时变更规则：直播中途关闭审查 → 违规列表立即只读+隐藏处置按钮，已触发未处置的 L2/L3 违规自动归档（L1 除外）
BR-AUDIT-021回放先审后发规则：回放只有经人工发布后才对观众可见；发布留档（发布人/时间）
BR-AUDIT-024多片段手动拼接规则：拼接触发、勾选、审核全部由运营在回放页手动完成，系统不自动拼接
BR-AUDIT-025双文件保留规则：有违规场次拼接后保留完整源码（只读·对账）+ 完整擦音（对外发布）双份；无违规场次源码即发布版
BR-AUDIT-027违规标记复审规则：回放播放器时间轴以彩色圆点标注违规时刻（红/黄/蓝），点击跳转复审；违规列表行点击联动跳转
BR-AUDIT-028片段与文件独立审核规则：每个 ReplaySegment 与 ReplayFile 单独审核（review_status/reviewer/reviewed_at），拒绝态标红禁用不参与拼接；文件审核通过同步联动对应片段状态
BR-AUDIT-029片段文件一一对应规则：segment_index = file_index 且 segment_id = source_segment_id；勾选集合 size 相等 + index 完全相等才可拼接；单文件场景免勾选免拼接
BR-AUDIT-030先审后拼与先审后发规则：所有文件审核通过 → 才可勾选拼接；拼接完成 → 才可发布；顺序不可颠倒，任一环节缺失按钮锁定
BR-AUDIT-031无违规场次免擦音规则：本场次无违规记录时隐藏擦音模式/擦音对比/违规统计/违规列表，拼接后仅生成源码发布版，跳过 AMS 擦音任务
BR-AUDIT-032已发布查看模式规则：已发布场次进入回放页仅展示完整文件（擦音后+源码）+ 场次信息，隐藏全部操作区，无发布按钮
