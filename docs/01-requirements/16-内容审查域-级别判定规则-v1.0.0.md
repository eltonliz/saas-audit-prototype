## 一、背景与设计原则

### 1.1 为什么需要自定义级别

腾讯云直播审核**本身不返回「L1/L2/L3」级别**，它只返回：

| 腾讯云返回字段 | 含义 | 示例 |
|---|---|---|
| `Label` | 恶意标签（内容类型） | `Porn` / `Terror` / `Illegal` / `Abuse` / `Ad` / `Custom` |
| `subLabel` | 子标签（细粒度） | `PornHigh` / `PornLow` / `Bloody` / `Contact` |
| `score` | 置信度 0-100 | `92` |
| `suggestion` | 审核建议 | `Block`（打击）/ `Review`（复审）/ `Pass`（正常） |

级别（L1/L2/L3/L4）是**平台业务层自定义**的，用于统一不同审核结果到一套处置策略（断流/封禁/警告/记录）。

### 1.2 设计原则

1. **类别定档为主，置信度校准为辅**：先由「内容类型」定档（保底层级），再用 `score` 置信度校准（低置信度才可能降档）。
2. **不可降级类别优先**：涉政、涉黄、涉暴、公共安全、社会安全、违法乱纪、广告法七类，无论 `score` 多低都不得降级（低置信度只转人工复核，不降档）。
3. **单一数据源**：所有级别判断必须走 `audit-level-config.ts`，禁止在页面组件中硬编码。
4. **管控对象**：仅主播音视频流（画面 + ASR 文本）；观众弹幕/评论走腾讯云 IM 云端审核，不在本体系内。

### 1.3 三层判定结构

```
腾讯云标签 (Label + subLabel)   →   业务类别   →   级别 (L1~L4)
    [第一层：标签归类]              [第二层：类别定档]      [第三层：Score校准]
```

- **第一层**：把腾讯云的 Label/subLabel 归入平台的「业务类别」（11 类）。
- **第二层**：每个业务类别有固定的「保底层级」。
- **第三层**：用 `score` 置信度在校准规则内微调（仅可降级类别允许降档）。

## 二、级别定义（L1 / L2 / L3 / L4）

| 级别 | 名称 | 处置方式 | 告警色 | 可否降级 |
|------|------|---------|--------|---------|
| **L1** | 核心 | 断流 + 封禁 | 红 | ❌ 不可降级 |
| **L2** | 高危 | 断流 | 红 | ❌ 不可降级 |
| **L3** | 中危 | 警告（记录/忽略/断流可选） | 黄 | ⚠️ 部分可降级 |
| **L4** | 低危 | 记录 | 蓝 | ✅ 可降级 |

> 说明：本次审阅**重点定义 L1/L2/L3**；L4 作为兜底级（未命中或边缘内容），保留定义以保证规则完整性。

---

## 三、判定总公式

```
最终级别 = Score校准( 类别定档( 腾讯云标签映射的业务类别 ) )
```

判定顺序：
1. 取腾讯云回调的 `Label` + `subLabel` + `score`；
2. 按**第四章映射表**将标签归入业务类别；
3. 按类别取**保底层级**；
4. 按**第五章 Score 校准**微调；
5. 得最终级别，联动处置策略与告警色。

## 四、腾讯云标签 → 业务类别 → 级别 映射表（核心）

### 4.1 L1 核心（断流 + 封禁，不可降级）

| 腾讯云标签 | subLabel 细分 | 业务类别 | 说明 |
|---|---|---|---|
| `Polity` / `PolityFace` | 政治人物、政治事件、政治敏感 | **涉政** | 任何涉政内容一律 L1，零容忍 |
| `Porn` | `PornHigh`（性行为、裸露等严重色情） | **涉黄（严重）** | 严重色情一律 L1 |

### 4.2 L2 高危（断流，不可降级）

| 腾讯云标签 | subLabel 细分 | 业务类别 | 说明 |
|---|---|---|---|
| `Porn` | `PornLow`（轻度色情、擦边） | **涉黄（轻度）** | 轻度色情定 L2 |
| `Terror` | `Bloody`（血腥）/ `Knife` / `Gun` / `Weapon`（暴力攻击） | **涉暴** | 暴力攻击行为 |
| `Terror` | `Explosion`（爆炸物）/ 危险品 | **公共安全** | 公共安全威胁 |
| `Terror` / `Illegal` | `TerrorFace`（暴恐人物）/ 极端组织 / 煽动 | **社会安全** | 危害社会稳定 |
| `Illegal` | `Gamble`（赌博）/ `Drug`（毒品）/ `Fraud`（诈骗）/ 其他违法 | **违法乱纪** | 违法行为 |

> **代码实现说明（决策 2）**：级别判定层将 `Terror/Illegal` 统一归入 L2，`TENCENT_LABEL_TO_CATEGORY` 中 `Terror → violence`、`Illegal → illegal`，subLabel 细分（涉暴/公共安全/社会安全）仅用于「违规类别」标签展示，V1 暂不落 subLabel→类别的细分逻辑。

### 4.3 L3 中危（警告，部分可降级）

| 腾讯云标签 | subLabel 细分 | 业务类别 | 可否降级 |
|---|---|---|---|
| `Ad` | `Contact`（联系方式）/ `QrCode`（二维码）/ 广告 | **广告法** | ❌ 不可降级 |
| `Abuse` | —（谩骂） | **辱骂** | ✅ 可降级 |
| `Custom` | 命中违禁词 | **一般违禁词** | ✅ 可降级 |
| `Sexy` / `Moan` | `SexyHigh` / `SexyLow`（性感低俗）/ `Moan`（呻吟娇喘） | **低俗** | ✅ 可降级 |

### 4.4 L4 低危（记录，可降级，兜底）

| 腾讯云标签 | 业务类别 | 说明 |
|---|---|---|
| `Custom` | 疑似/边缘词 | 命中边缘词 |
| 其他未明确命中 | 兜底 | 记录备查 |

## 五、Score 置信度校准规则

| score 区间 | 校准规则 |
|---|---|
| **≥ 80** | 维持类别定档（高置信，V1 不自动升档，升档由人工处置决策） |
| **50 ~ 79** | 维持类别定档 |
| **< 50** | 可降级类别 → 降一档 + 转人工复核；不可降级类别 → 维持原级 + 转人工复核 |

> **关键**：不可降级七类（涉政/涉黄/涉暴/公共安全/社会安全/违法乱纪/广告法）即使 score < 50 也**维持原级**，只额外标记「转人工复核」，防止低置信度误判漏掉严重违规。

## 六、判定流程（决策顺序）

```
腾讯云回调(Label + subLabel + score)
        │
        ▼
① 标签归类：Label/subLabel → 业务类别
        │
        ▼
② 类别定档：业务类别 → 保底层级 (L1~L4)
        │
        ▼
③ Score校准：
   ├─ score ≥ 50 → 维持定档
   └─ score < 50 → 可降级类别降一档；不可降级类别维持 + 转人工
        │
        ▼
④ 输出最终级别 → 联动处置(断流/封禁/警告/记录) + 告警色(红/黄/蓝)
```

---

## 七、兜底与边界规则

1. **未命中标签**：腾讯云返回 `Normal` 或未命中任何恶意标签 → 不产生违规记录。
2. **未知标签兜底**：出现映射表之外的标签 → 按 L4 记录 + 转人工复核，不丢弃（BR-AUDIT-005 全量接收）。
3. **多标签同时命中**：取最高级别（如同时命中 PornHigh 和 Ad → 取 L1）。
4. **涉暴/公共安全/社会安全边界**：三者均来自腾讯云 `Terror`/`Illegal` 标签，需结合 subLabel + 内容语义细分；建议运营侧配置关键词库辅助细分（见第八章待确认项）。

## 八、已确认决策（2026-08-13）

| # | 决策项 | 结论 |
|---|---|---|
| 1 | 音频侧涉政/违法/暴恐识别 | **自定义词库兜底**：音频文本审核原生只返回 `Porn/Abuse/Ad/Custom/Moan`，涉政/违法/暴恐三类敏感词录入「自定义词库」，命中 `Label=Custom` 后二次判断归入对应类别；画面审核原生返回 `Polity/Terror/Illegal` |
