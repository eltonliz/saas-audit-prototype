## 一、核心规则（一句话）

> **直播结束即触发拼接，拼接成功自动进入擦音；拼接失败标记状态并提示运营介入。**

不做缓冲窗口、不做断流时长判定、不做缺口标注——这是产品规则，不是技术实现。后端拼接服务的复杂度（重试、并发、断点续传）由 real 阶段对接腾讯云媒体处理 MPS 时再细化。

## 二、机制总览

### 2.1 触发时机

| 触发条件 | 时机 | 备注 |
|---|---|---|
| 推流中断超过 N 秒 | 直播中（实时） | 产生新片段，`segment_index++` |
| 直播状态：live → ended | 直播结束（断流/手动结束） | 系统判定结束，触发拼接 |
| 主播在缓冲窗口内重连 | 不触发拼接 | 视为继续直播 |

> 说明：上表中"缓冲窗口"由后端实现细节决定，产品规则只需保证"直播真正结束才触发拼接"。

### 2.2 拼接流程（3 步）

| 步骤 | 动作 | 输入 | 输出 | 失败处理 |
|---|---|---|---|---|
| ① 触发 | 系统扫描该 stream_id 所有片段，按 `segment_index` 排序 | 场次 ID | 待拼接片段列表 | — |
| ② 拼接 | FFmpeg concat 合并为完整源码文件 | 待拼接片段列表 | 源码文件（未擦音） | `merge_status=failed` |
| ③ 后续 | 源码文件触发擦音 → 生成回放文件 → 人工审核 | 源码文件 | 回放文件（已擦音） | 擦音失败独立处理 |

### 2.3 文件产出

| 文件 | 类型 | 是否可播放 | 是否对外 | 用途 |
|---|---|---|---|---|
| **源码文件** | 完整拼接版、未擦音 | ✅ 可播放（只读） | 租户 + 运营可见 | 对账 / 审计 / 复核违规内容 |
| **回放文件** | 完整拼接版、已擦音 | ✅ 可播放 | 租户 + 观众可见 | 对外发布版本 |

### 2.4 拼接状态（merge_status）

| 状态 | 含义 | UI 展示 | 后续动作 |
|---|---|---|---|
| `pending` | 直播结束，等待系统处理 | 「待拼接」灰色标签 | — |
| `merging` | 系统正在拼接 | 「拼接中」橙色标签 + 进度条 | — |
| `completed` | 拼接成功，已进入擦音/审核 | 「已自动拼接」绿色标签 | 自动擦音 |
| `failed` | 拼接失败，需运营介入 | 「拼接失败」红色标签 + 失败原因 | 提示运营联系技术 |

### 2.5 拼接失败处理

| 失败类型 | 表现 | 处置 |
|---|---|---|
| 片段缺失/损坏 | 单/多片段无法读取 | `merge_status=failed`，回放页提示「片段 N 损坏，请联系技术」 |
| 拼接超时 | 重试 N 次仍超时 | `merge_status=failed`，提示运营 |
| 单一片段（无断流） | 只有一个片段 | 不触发拼接，直接进入擦音 |

## 三、与擦音/审核的关系

```
[直播中] 检测断流 > N秒 → 切片段，segment_index++
     ↓
[直播结束] 状态 live → ended
     ↓
[① 触发拼接] 系统扫描所有片段，按 segment_index 排序
     ↓
[② 拼接] FFmpeg concat → 源码文件(merge_status=completed)
     ├─ 失败 → merge_status=failed，提示运营，不进入擦音
     └─ 成功 ↓
[③ 擦音] 源码文件 → 擦音任务 → 回放文件(已擦音)
     ↓
[审核] 回放文件 → 人工审核（通过→发布/不通过→重新擦音）
     ↓
[发布] 回放对租户/观众可见生效
```

### 关键顺序铁律
- **先拼接 → 后擦音**（不颠倒）
- **擦音只对完整文件做一次**（不擦片段）
- **拼接失败不擦音**（无擦音对象）

## 四、片段数据结构

### ReplaySegment（片段）

| 字段 | 类型 | 说明 |
|---|---|---|
| `segment_id` | String | 片段唯一 ID |
| `stream_id` | String | 所属场次 |
| `segment_index` | Int (≥1) | 片段序号，按开始时间排序 |
| `start_time` | String | 片段开始时间 |
| `end_time` | String | 片段结束时间 |
| `duration` | String | 片段时长 |
| `break_reason` | String | 断流原因（推流网络抖动 / 主播端断流重连 / 网络中断 / 手动切流等） |
| `source_url` | String | 源码片段地址 |

### ReplayFile（拼接后文件）

| 字段 | 类型 | 说明 |
|---|---|---|
| `play_url_original` | URL | 源码文件地址（拼接后未擦音） |
| `play_url_muted` | URL? | 回放文件地址（擦音后） |
| `is_muted` | Boolean | 是否已擦音 |
| `allow_play` | Boolean | 是否允许播放 |
| `merge_status` | Enum | pending / merging / completed / failed |
| `segment_count` | Int (≥1) | 由多少个片段拼接而成（=1 表示无断流） |
