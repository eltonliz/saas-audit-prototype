## 3. 背景与问题陈述

内容审查域是 SAAS 平台的**平台级运营管控能力**，针对主播直播内容（音频/视频推流）进行实时审查和擦音处理，并对回放文件执行违规处理与人工发布管控，确保直播与回放内容符合法律法规要求。

### 核心问题

| 问题编号 | 问题 | 严重程度 |
|----------|------|----------|
| AUDIT-ISSUE-001 | 直播中主播出现违规内容无实时擦音能力 | 🔴 高 |
| AUDIT-ISSUE-002 | 直播回放文件未经擦音处理即开放观看 | 🔴 高 |
| AUDIT-ISSUE-003 | 回放断流产生多片段时无法可靠拼接为完整文件 | 🔴 高 |
| AUDIT-ISSUE-004 | 平台对违规内容缺乏分级管控与人工处置闭环 | 🟡 中 |

### 需求边界

| 管控对象 | 审查内容 | 技术方案 | V2 |
|---|---|---|---|
| 主播直播内容 | 音频/视频流（画面 + ASR 文本） | 腾讯云直播审核 + 擦音（真实对接） | ✅ |
| 回放文件 | 音频擦音 + 片段拼接 + 人工发布 | 腾讯云 AMS + FFmpeg concat | ✅ |
| 观众文本消息 | 弹幕/聊天 | 腾讯云 IM 云端审核（独立体系，不在本域） | ❌ |

### 级别体系（平台自定义三级）

腾讯云仅返回 `Label / subLabel / score / suggestion`，**不提供级别划分**。级别为平台业务层自定义（详见子文档《级别判定规则》）：

| 级别 | 名称 | 告警色 | 处置方式 | 可否降级 |
|------|------|--------|---------|---------|
| **L1** | 高危 | 红 | 审核引擎直接断流 + 封禁 | ❌ 不可降级 |
| **L2** | 中危 | 黄 | 运营可记录 / 断流 | ❌ 不可降级 |
| **L3** | 低危 | 蓝 | 运营可记录 / 忽略 | ✅ 部分可降级（score<50 降一档转人工） |

- **L1 不可降级七类**：涉黄 / 涉政 / 涉暴 / 公共安全 / 社会安全 / 违法乱纪 / 广告法——无论置信度高低一律维持 L1，租户不可关闭、不可降级。
- L4 作为兜底级（未命中或边缘内容，仅记录备查）保留定义，页面仅展示 L1/L3 三档统计。
- 级别判定采用三层结构：标签归类 → 类别定档 → score 校准（<50 且可降级才降一档并转人工复核）。

## 5. 范围

### In-Scope（V2）

**运营后台（PC）**：
- 租户管理列表新增「内容审查」开关列（开启直接生效；关闭弹二次确认弹窗，含七类不可降级底线提示与在播场次警告）

**租户后台（PC）——直播中控**：
- 直播列表入口复用（直播中控台 / 更多→历史违规列表 / 更多→查看回放 / 回放管理 Tab）
- 内容审查页签：实时违规告警（红/黄/蓝三档统计 + 待处理角标 + 实时列表）
- 违规详情抽屉（证据录音试听 + 处置按钮按级别收敛）
- 违规处置（记录 / 断流 / 忽略；处置说明≥10 字；30 秒超时自动记录）
- 处理方式切换（静音 / 提示音覆盖，实时同步观众端）
- 主播侧警示条（记录=橙色 8 秒；断流=红色常驻；观众无感知）
- 历史违规列表（已结束场次只读档案）

**租户后台（PC）——回放管理**：
- 回放管理列表（待核对 / 已发布 / 已驳回三态 + 待核对徽标 + 删除）
- 回放页：片段/文件逐个审核 → 勾选一一对应 → 手动拼接 → 人工发布（v2.0.0）
- 无违规场次免擦音（源码即对外发布版）
- 已发布查看模式（仅展示完整文件，隐藏操作区）
- 擦音前后对比 / 播放器时间轴违规标记复审

**观众端（H5 375px）**：
- 静音处理效果（🔇 + 画面变暗 + 进度条，2-5 秒）
- 提示音覆盖效果（🎧 + 声波动画，2-5 秒）
- 判定未送达提示（与处理效果互斥）
- 断流结束页（"直播已结束，该直播因内容违规已被终止"）

**平台侧基础设施**：
- 审核回调接入服务（网关验签 + 幂等去重 + 级别判定 + MQ 分发）
- 实时消息推送（中控告警 / 观众端擦音指令）
- 断流指令通道（审查服务 → 腾讯云 断流指令接口）
- 回放擦音任务（AMS）与拼接任务（FFmpeg concat）调度

### Non-Goals

- 观众弹幕/评论审查（腾讯云 IM 独立处理）
- 自研推流端审查能力（依赖腾讯云）
- 违规统计看板（V3）
- 平台管控策略下发（V3）
- 租户个性化规则扩展（V3）
- 腾讯云审核模板/擦音任务的配置管理界面（由平台运维在腾讯云控制台人工配置，系统仅消费回调与任务结果）

## 10. 功能需求列表与用例（FN/UC）

### FN-AUDIT-INFRA-001 审核回调接入服务（基础设施）

| 字段 | 值 |
|---|---|
| 功能名称 | 审核回调接入服务 |
| 功能编号 | FN-AUDIT-INFRA-001 |
| 所属模块 | 内容审查域-平台基础设施 |
| 自动化类型 | [系统自动]事件驱动 |

**前置条件**：
1. 腾讯云直播审核已开启并配置回调地址（回调模板由平台运维在腾讯云控制台人工配置）
2. 审查服务与 MQ 已就绪

**基本流程**：
1. [系统自动] 腾讯云审核引擎对推流执行实时审核（音视频画面 + ASR 音频文本），命中违规即回调 `POST /audit/callback`（携带签名与 `Label/subLabel/score/suggestion/asr_text/duration/seq/stream_id` 等字段）
2. [系统自动] 回调网关验签（签名不合法直接拒绝，返回 401，不进入业务）
3. [系统自动] 幂等去重（按回调唯一键去重，重复事件返回 200 但不重复入库）
4. [系统自动] 验签去重通过后立即返回 200 ACK
5. [系统自动] 事件写入 MQ，异步分发至审查服务
6. [系统自动] 审查服务执行级别判定（三层：标签归类 → 类别定档 → score 校准，输出 L1/L2/L3）
7. [系统自动] 违规记录入库（含原始回调 JSON 留档，BR-AUDIT-010）
8. [系统自动] 多路分发：
   - 直播中控：实时消息推送告警（待处理角标 +1）

   - **单文件场景**：仅 1 个回放文件时无 checkbox，自动视为完整回放，无需拼接

   - **擦音模式单选 / 擦音前后对比 / 违规记录列表**：有违规时显示；无违规时全部隐藏

3. [手动] **① 逐个审核**：运营对每个回放文件点「审核通过」（待审核 → 已审核）；文件审核状态同步联动对应片段的审核状态
4. [手动] **② 勾选对应**：多文件场景下勾选序号一一对应的片段与文件（集合 size 相等且 index 完全相等）；单文件场景自动跳过

6. [系统自动] **④ 生成完整文件**：
   - 有违规场次：完整源码文件（只读·对账用）+ 完整回放文件（已擦音·对外发布版）双份

**失败处理**：片段缺失/损坏 → failed + 提示片段 N 损坏；重试超限 → failed + 提示运营联系技术；校验失败（勾选不匹配）→ 按钮直接锁定，不进入处理流程。

**后置条件**：完整回放文件生成（双文件保留 BR-AUDIT-025）；拼接产物仅供审核，发布由 FN-AUDIT-PC-005 独立完成

3. [系统自动] **提示音覆盖模式**：违规声音被「嘀」声覆盖，中央显示铃铛图标 + 声波跳动动画，2-5 秒后自动恢复
4. [系统自动] 处理生效期间底部右侧显示状态标识（静音中=红 / 提示音覆盖中=橙）
5. [系统自动] **判定未送达**（推送失败）：画面顶部橙色提示「直播中控尚未收到此违规的判定结果」（与处理效果互斥，不同时出现），恢复后自动消失
6. [事件驱动] **断流结束页**（L1 引擎直断或运营断流）：直播声音立即停止，全屏「直播已结束」+「该直播因内容违规已被终止」，直播不再恢复

**UI 叠加层级**：主播信息栏/关闭按钮 > 审查效果层 > 视频画面/弹幕/商品卡片 > 底部操作栏；效果层居中不遮挡主播面部核心区域。

**备选流程**：
- 2a. 处理方式由直播中控切换后实时同步（FN-AUDIT-PC-003），此后效果按新方式生效
- 6a. 租户关闭审查开关后，观众端不做任何处理，直播全程无变化

**数据范围(R/W)**：R: 处理指令（实时消息推送）/ W: 无（观众端只感知不写入）

**后置条件**：违规内容不传到观众耳朵；处理过程可感知但不惊扰；断流有明确结束说明

**关联UC**：UC-AUDIT-004
