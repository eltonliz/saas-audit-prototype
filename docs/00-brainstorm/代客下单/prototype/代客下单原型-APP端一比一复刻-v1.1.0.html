P8 他人支付卡片 + 现场二维码 → 客户代付页
业务逻辑
  1. 凭证（BR-08）：卡片仅商品名+首图+「待支付」不展示金额；文案中性；双形态共用同一 token
  2. token 生命周期：时效=支付窗口（30 分钟）；吊销=状态置位+版本比对；金额变更/已支付/已关闭/取消 → 即时吊销，打开显失效页；金额≠快照阻断+提示重发（Q5）
  3. 失败回传：客户支付失败实时推送操作店员（P10 标记「客户支付失败 N 次」）；连续失败 2 次提示改垫付/重新生成
  4. 合规：PIPL 告知+收款方明示（服务商模式 sub_appid/sub_openid，Q1 前置）；超阈值金额二次确认
