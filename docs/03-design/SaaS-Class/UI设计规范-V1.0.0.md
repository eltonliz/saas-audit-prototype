# SaaS-Class 原型 UI 设计规范 V1.0.0

> 来源：追伴 SAAS 平台实测 + 蓝湖设计稿（SAAS-追伴 02-新图）
> 采集日期：2026-08-19
> 用途：SaaS-Class 原型 1:1 还原参考

---

## 一、设计原则

1. **高保真还原**：PC 后台对齐追伴平台风格；APP 端 375px 移动端规范
2. **终端分离**：PC 用 Element Plus 组件库；APP 用纯 H5 原生组件（禁止混用）
3. **一致性**：全站配色/字体/间距/圆角统一

---

## 十、弹窗/抽屉规范

### 10.1 PC 弹窗（el-dialog）
- 圆角：8px
- 遮罩：`rgba(0,0,0,0.5)`
- 标题：18px / 600
- 关闭按钮：右上角 ×
- 底部按钮：右对齐，取消(次) + 确认(主)
- 居中显示

### 10.2 PC 抽屉（el-drawer）
- 方向：rtl（右侧滑出）
- 宽度：50%（编辑表单）/ 640px（管理抽屉）
- 顶部标题栏 + 关闭按钮
- 底部操作按钮

### 10.3 APP 底部弹层
- 从底部滑出（transition translateY）
- 圆角：16px 16px 0 0
- 遮罩：`rgba(0,0,0,0.5)`
- 最大高度：80vh
- 内边距：20px
- 标题：16px / 600
- 底部双按钮（取消 + 确认）

## 十一、筛选区规范（PC）

```
┌──────────────────────────────────────────────────┐
│ [标签:] [输入框] [下拉] [日期] ...   [新增] [筛选] [重置] [批量] │
└──────────────────────────────────────────────────┘
```
- 布局：flex 横向排列，间距 12px
- 标签文字：14px / `#1F2C3E`
- 输入框宽度：160px~260px
- 日期范围：260px
- 按钮组靠右
- 底部边距：16px

---

## 十二、分页器规范（PC）
- 位置：表格下方左侧
- 布局：total, sizes, prev, pager, next, jumper
- 默认每页：10/20/30 条
- 顶部边距：16px

---

## 十三、APP 页面结构模板

```
┌─────────────────────┐
│ [角色切换条 40px]    │
├─────────────────────┤
│ [返回←] [页面标题]   │  ← header
├─────────────────────┤
│                     │
│   内容区             │
│   (卡片/列表/表单)   │
│                     │
├─────────────────────┤
│ [CTA 固定按钮 44px]  │  ← 可选
├─────────────────────┤
│ [底部Tab 56px]      │  ← Tab页才有
└─────────────────────┘
```
- 容器：max-width 375px / margin 0 auto / min-height 100vh / background #F9FAFB
- 底部留白：56px~80px（避开Tab+CTA）
