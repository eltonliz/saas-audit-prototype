## 二、课堂模块（3个子页面，顶部Tab切换）

### 2.1 课程库页面（/classroom/courseLibrary）

**筛选区**：创建时间(日期范围) + 课程名称(文本) + 课程编号(文本) + 所属分类(下拉) + 按钮(新增/筛选/重置/批量全选)

**表格列**：复选框 | 课程编号 | 课程名称 | 所属分类 | 课程视频内容(查看视频按钮) | 课程相关题库(查看题库按钮) | 创建时间 | 状态(启用) | 操作(编辑/禁用)

**行操作**：查看视频(弹窗播放器) / 查看题库 / 编辑 / 禁用

### 2.2 课程编辑/新增表单（右侧滑出抽屉）

**基本信息区**：课程名称(文本) + 所属分类(下拉) + 课程介绍(文本域)

**视频内容区**："+ 选择视频"按钮 → 视频表格（视频编号/名称/文件/格式/大小/时长/分类/是否答题switch/奖励/操作）

**配置区**：
- Switch开关：虚拟人数设置、奖励设置
- 数字步进器：最小虚拟人数(1)/最大虚拟人数(100)/奖励数值(50)/时长百分比(100)
- 单选组：允许快进(允许/不允许) / 允许倍速(允许/不允许)

**底部**：取消 + 保存

### 2.3 课程类型页面（/classroom/courseType）

**筛选区**：日期范围 + 分类名称(文本) + 按钮(新建/筛选/重置/批量全选)

**表格列**：复选框 | 分类编号 | 分类名称 | 分类图标 | 相关题库数(可点击) | 相关课程数(可点击) | 状态 | 创建时间 | 操作(编辑/禁用)

### 2.4 题目库页面（/classroom/questionBank）

**筛选区**：日期范围 + 题目名称(文本) + 所属分类(下拉) + 题目类型(下拉) + 按钮(新增/筛选/重置/批量全选)

**表格列**：复选框 | 题目编码 | 题目名称 | 题目类型(单选/多选) | 题目选项(A:{1};B:{2}...) | 题目答案(A,B,C) | 创建人 | 创建时间 | 状态 | 操作(编辑/禁用)

## 四、设计风格规范

### 技术栈
Vue3 + Naive UI（n-data-table/n-modal/n-menu/n-switch/n-radio/n-select）

### 配色
- 主色调：蓝色系（按钮、链接）
- 状态标签：绿色"启用"
- 背景：白色/浅灰
- 表格边框：浅灰

### 组件风格
- **表格**：标准数据表格，表头浅灰背景，行hover高亮
- **按钮**：主按钮(填充) / 次按钮(边框) / 文字按钮
- **表单**：右侧滑出抽屉面板（非全屏，背景可见）
- **弹窗**：居中模态+遮罩
- **输入框**：圆角矩形边框
- **Switch**：蓝色开启/灰色关闭
- **数字步进器**：- [数字] +
- **单选**：圆形，选中蓝色
- **日期选择器**：双输入框(开始+结束)
- **分页**：页码+每页条数+跳转

### 间距与排版
- 表格行高40-50px
- 筛选区控件横向排列
- 表单标签左对齐
- 时间格式：YYYY-MM-DD HH:mm:ss

### 交互特点
- 表格操作列为文字按钮（非图标）
- 编辑/新增用右侧抽屉面板
- 弹窗点击遮罩不关闭

## 五、对 SaaS-Class 的参考价值

| 追伴页面 | SaaS-Class 对应 | 参考点 |
|---|---|---|
| 课程库 | CourseManagePage | 筛选区布局、表格列、编辑抽屉、视频管理 |
| 课程类型 | 分类管理 | 分类CRUD（当前SaaS-Class用常量，可扩展为管理页） |
| 题目库 | QuestionDrawerPage | 题目选项格式(A:{1};B:{2})、单选/多选类型 |
| 视频管理 | LessonDrawerPage | 视频关联、是否答题switch、奖励配置 |
| 虚拟人数 | — | SaaS-Class 暂无，可考虑加入 |
| 允许快进/倍速 | — | 课时学习配置项 |

### SaaS-Class UI 优化建议
1. 课程管理筛选区对齐追伴布局（日期范围+名称+编号+分类+按钮组）
2. 编辑表单改右侧抽屉（当前用居中dialog，追伴用右侧滑出抽屉）
3. 视频内容区加是否答题switch+奖励配置
4. 表格操作列保持文字按钮风格
5. 状态列用"启用/禁用"而非彩色标签
