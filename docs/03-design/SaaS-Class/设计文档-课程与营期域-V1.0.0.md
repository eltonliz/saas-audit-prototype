## §1 交互原则

### 1.1 两终端设计策略（1:1 对齐 SugarMate + SaaS 风格）

| 终端 | 角色 | 密度 | 栅格 | 设计语言 | 核心交互特征 |
|---|---|---|---|---|---|
| PC-后台 | 管理员/讲师/助教 | 高密度 | 24列（1440px 基准） | Element Plus 数据管理型 | 表格集约+抽屉表单+状态流转+审核操作 |
| APP-学员端 | 学员 | 低密度 | 6列（375px 基准） | 移动端自然触感 | 信息卡片+底部操作栏+Tab切换+全屏沉浸 |

### 1.2 核心交互原则

| # | 原则 | 说明 | 适用终端 |
|---|---|---|---|
| IP1 | **渐进式揭露** | 列表先展示概要，点击展开详情；订单详情抽屉展示支付流水 Timeline | 全部 |
| IP2 | **行动召唤** | 审核操作（通过/驳回）按钮置顶；支付按钮固定底部；红包领取强提示 | 全部 |
| IP3 | **防呆设计** | 不可逆操作（退款/证书撤销/讲师离职）二次确认+警告提示 | PC |
| IP4 | **状态可见** | 状态徽标彩色分层（草稿灰/待审核黄/已发布绿/已下架红/已驳回红）；支付流水状态图标 | 全部 |
| IP5 | **资金安全感知** | 金额统一展示「元」（分→元转换）；退款回滚警告；红包余额实时显示 | 全部 |
| IP6 | **状态机约束** | 不可流转的按钮置灰禁用（如营期 ended 不可回退）；模式创建后不可改字段禁用 | PC |
| IP7 | **快照锁定感知** | 讲师离职后课程/营期讲师字段标注「已离职·快照」 | PC |
| IP8 | **移动优先** | APP 大触控区（≥44px）+ 底部操作栏固定 + 视频全屏播放 | APP |
| IP9 | **激励即时反馈** | 红包领取 Toast 动画 + 积分入账 Toast + 打卡成功动画 | APP |
| IP10 | **审核模糊回显** | 评价审核未通过内容 blur(3px)+opacity:0.6+「审核中」标签 | 全部 |

### 1.3 交互粒度分级

| 级别 | 定义 | 示例 |
|---|---|---|
| L1-页面级 | 完整页面交互，含多区块联动 | 营期管理页（列表+统计+抽屉+状态流转） |
| L2-区块级 | 页面内区块交互 | 统计卡片区、表格区、筛选区、操作区 |
| L3-组件级 | 表单/按钮/表格/搜索等组件 | 审核确认弹窗、排课编辑抽屉 |
| L4-状态级 | 组件内状态变化 | 按钮置灰/加载动画/进度条/状态徽标变色 |

### 6.1 退款确认弹窗（M-COURSE-014）

**触发**：PG-PC-007/008 点击「退款」（仅 paid 订单）

**内容**：

  > 1. 营期订单 → 已退款
  > 2. 分成账单 → 已取消
  > 3. 合同 → 已取消
  > 4. 学员退出营期

**按钮**：确认退款（Danger 红色，二次确认） / 取消

### 6.2 提现审核弹窗（M-COURSE-017）

**触发**：PG-PC-012 点击「审核」

**内容**：
- 提现信息（提现号/受益人/金额/关联账单）
- 收款账户信息
- **打款凭证号**（必填 input，D11 线下打款凭证）

**按钮**：审核通过（Primary，填凭证号后可用） / 驳回（Danger，填原因）

### 6.3 营期新增弹窗（M-COURSE-009）

**触发**：PG-PC-005 点击「新增营期」

**表单字段**：
- 基本信息：title/description/cover_url
- 专题：series_id（选专题树，D5）
- 模式：mode（live/recorded，创建后不可改 D26，编辑时禁用）
- 时间：start_date/end_date/total_days（自动计算）
- 价格：is_paid 开关 + price（is_paid=true 时显示，分单位 D9）
- 分成：commission_enabled 开关 + lecturer_rate/assistant_rate/platform_rate（三联动自动计算，三者=1，D10）
- 证书：certificate_checkin_threshold（默认 0.8，D8）
- 主讲：main_lecturer_id（选讲师，快照锁定 D16）
- 报名：capacity/enroll_deadline
- 红包：dailyRedPacketMode（by_course/by_camp，D35）
- 售货：allow_products（默认 false，禁用 + 标注「营销功能·本期未启用」D4）

**校验**：
- 日历约束：validateCampCalendarNoOverlap（同专题不交叉 BR-CAMP-CAL-04）
- 分成比例：validateCommissionRate（三者=1，D10）

### 6.4 课程新增弹窗（M-COURSE-004）

**表单字段**：
- 基本信息：title/description/cover_url
- 分类：category_id（选租户自定义分类树，D2）
- 标签：tags
- 讲师：lecturer_id（选讲师，快照锁定 D16）
- 来源：source（upload/live_replay，D3）；live_replay 时显示 source_live_session_id
- 模式：mode（recorded/live）
- 可见性：visibility（public/camp_only）
- 价格：is_paid 开关 + price（分单位 D9）
- **红包配置（D35）**：
  - completionRewardEnabled（完播即领开关）
  - answerRewardEnabled（答题奖励开关）
  - rewardType（points/red_packet_rule，可共存 D35）
  - rewardAmount（指定金额/积分）
  - redPacketRuleId（rewardType=red_packet_rule 时选规则）

### 6.5 退款原因 6 选 1 弹窗交互（APP 端 PG-APP-011）

**触发**：学员在订单页点击「申请退款」→ 跳转退款申请页

**交互内容**：
- 退款原因 Radio Group（6 选 1，必选）：
  1. 质量问题（课程内容与描述不符）
  2. 时间冲突（无法参加营期直播）
  3. 个人原因（个人行程变动）
  4. 重复购买（误操作重复下单）
  5. 服务不满意（讲师/助教服务态度问题）
  6. 其他（自定义说明）
- 问题描述 textarea（必填，最少 10 字）
- 「其他」选项 → 显示补充说明 input
- 提交按钮 → createRefundRequest → pending 状态

**约束**：仅 paid 状态订单可申请退款；退款原因必选；问题描述必填

### 6.6 支付倒计时 24h 交互（APP 端 PG-APP-004）

**触发**：学员创建支付单后（CampOrder: pending_pay）

**交互内容**：
- 订单详情页显示倒计时（24:00:00 格式，从创建时刻开始倒数）
- 倒计时 < 1 小时 → 文字变红 + 加粗警告「订单即将过期，请尽快支付」
- 倒计时 = 0 → 订单自动取消（SEQ-13 cleanTimeoutPayments）→ 显示「订单已过期」
- 支付成功 → 倒计时消失，按钮变「签署合同」
- 页面离开后回来 → 倒计时继续（基于 order.created_at 计算剩余时间）

**时序约束**：SEQ-12 支付超时 30 分钟自动取消支付单；SEQ-13 订单超时 24 小时自动取消订单

### 6.7 合同勾选确认交互（APP 端 PG-APP-010）

**触发**：支付成功后跳转合同签署页（Contract: pending_sign）

**交互内容**：
- 合同全文滚动预览（全屏，需滚动到底部才可操作）
- 底部固定操作栏：
  - Checkbox「我已阅读并同意《课程服务协议》」
  - 签署按钮（Checkbox 勾选后可用，否则置灰禁用）
- 滚动监听：未滚动到底部时 Checkbox 置灰 + 提示「请先阅读完合同」
- 滚动到底部 → Checkbox 可勾选
- 勾选 + 点击签署 → signContract → signed 状态 → Toast「签署成功」→ 返回营期详情
- 拒签 → 返回上一页（合同保持 pending_sign，可重新进入签署）

**约束**：合同状态 pending_sign → signed（不可逆）；未签署不影响学习（D 决策：支付即可学习，合同为合规留存）
